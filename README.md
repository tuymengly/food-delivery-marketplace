# food-delivery-marketplace
A medium-sized Food Delivery Marketplace web application built by a 3-member team.

## Local development

This repo has three independent apps: `backend/` (Laravel), `customer-frontend/`,
and `admin-restaurant/` (both React + Vite). To install and run all three
together with one command, see **[DEVELOPMENT_SETUP.md](DEVELOPMENT_SETUP.md)**.

Quick start (after first-time setup):

```bash
npm run dev
```
